# Thillai Nayagam — Industrial Automation & MES Controls Portfolio

A high-impact, modern personal portfolio and consulting website for **Thillai Nayagam Samia Pillai**, an Industrial Automation & MES Controls Expert with 20+ years of experience across manufacturing, solar, and energy environments.

## Highlights
- **Executive Engineering Aesthetic:** Built with a technical deep navy/charcoal color palette, technical grid lines, and crisp typography.
- **ISA-95 Architecture Visualizer:** Interactive OT–IT hierarchy model (Sensors &rarr; Field PAC/PLC &rarr; SCADA &rarr; MES &rarr; Cloud/Data).
- **Verified Business Metrics:** Real achievements ($150K scrap reduction, 17K/day throughput, 6-month greenfield startup, 85+ countries, 50% MTTR).
- **Interactive Scoping Assistant:** Client-side project scoping and email inquiry generator (`mailto:thillaiine@gmail.com`).
- **100% Static & Lightweight:** Zero database or backend dependencies, optimized for instant load times and SEO.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **SEO:** Open Graph, Twitter Cards, Schema.org Person JSON-LD

## Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

## Deployment to Vercel

This project is ready for one-click deployment on **Vercel**:

1. Push this repository to **GitHub / GitLab / Bitbucket**.
2. Go to [Vercel Dashboard](https://vercel.com/new) and select **Import Project**.
3. Vercel will automatically detect **Vite / React**:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
4. Click **Deploy**.
